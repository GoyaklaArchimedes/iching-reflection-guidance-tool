# The I Ching Reflection & Guidance Tool

An interactive psychologically grounded reflective companion inspired by the I Ching.

Designed for contemplation, emotional insight, journalling, and symbolic reflection rather than fortune telling.

Features:
- authentic King Wen structure
- weighted yarrow-style casting
- offline-first single-file HTML
- privacy-focused
- printable reflective workbook style
- no accounts or logins required
